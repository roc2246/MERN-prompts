# Responsive and Accessibility Review

Load for layout, responsive, interaction, or accessibility-related stylesheet reviews.

- Preserve the intended appearance unless visual change is requested.
- Prefer mobile-first breakpoints when consistent with the project.
- Check overflow, fixed dimensions, viewport assumptions, touch targets, readable text, focus-visible states, contrast-related styling, and reduced-motion behavior.
- Avoid hover-only interaction signals when keyboard/touch users need equivalent feedback.
- Verify selectors against the corresponding markup/components before renaming or removing them.
