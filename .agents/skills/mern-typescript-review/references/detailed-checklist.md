# Deep Checklist

Check `any`/unsafe assertions, `unknown` narrowing, nullability, discriminated unions, literal preservation, generic constraints, indexed/keyed access, optional properties, exported type/API design, async return types, error typing, domain-model reuse, React prop/event types, Express request augmentation, Mongoose typing, and `tsconfig` strictness. Prefer inference for locals; add explicit types where they protect public/shared boundaries. Never use compile-time types as runtime validation.
