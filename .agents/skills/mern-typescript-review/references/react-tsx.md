# React and TSX

Load for frontend TypeScript reviews.

- Review props, children, event handlers, refs, context defaults, hook return types, route params, forms, and API data.
- Watch for state initializers that produce weak inference or confusing nullable states.
- Use discriminated unions for async UI state when they materially reduce invalid combinations.
- Avoid unnecessary JSX assertions and unnecessary `React.FC`.
- Do not recommend generics, `useMemo`, or `useCallback` without a concrete need.
- Runtime-validate external API/storage/form data before treating it as a trusted application type.
